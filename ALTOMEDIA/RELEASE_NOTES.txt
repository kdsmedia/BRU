BAHASA INDONESIA
------------------------------------------------------------
BERUANG v2.4.3 — Splashscreen Berlogo & Naik Kelas Anti-Turun

Pembaruan v2.4.3 memperbaiki 2 keluhan pengguna seputar tampilan saat
aplikasi dibuka dan fitur Naik Kelas (tier).

Yang diperbaiki di v2.4.3:
- LOGO ANDROID DEFAULT SAAT APLIKASI DIBUKA (fix splashscreen): tema
  splash bawaan Android memakai ikon aplikasi generik ketika ikon splash
  tidak diatur secara eksplisit, sehingga pengguna melihat "logo Android
  default" sesaat sebelum aplikasi tampil. Kini ikon splash secara
  eksplisit memakai logo BERUANG: aplikasi langsung menampilkan
  splashscreen berlogo BERUANG lalu berlanjut mulus ke layar memuat.
- NAIK KELAS TIDAK BISA DOWNGRADE: sebelumnya pengguna bisa berpindah ke
  tier yang lebih rendah lewat tombol "Gunakan" di lembar Naik Kelas.
  Kini tier bersifat satu arah (hanya bisa naik): tier yang sudah
  terlampaui ditampilkan sebagai "Terlampaui" dan tidak bisa dipilih,
  dan repository menolak setiap upaya penurunan kelas ("Kelas akun tidak
  bisa diturunkan").

Catatan teknis:
- Android minSdk 23 (Android 6.0+) sampai targetSdk/compileSdk 37.
- Dibangun dengan Kotlin + Jetpack Compose, Supabase Kotlin 3.0.0,
  Coil (gambar), AdMob. Backend AI: Supabase Edge Function (Groq).
- Backend: Supabase (Postgres, Auth, Storage, Realtime).
- Build dirilis dengan keystore ALTOMEDIA.jks (alias kdsmedia).

Catatan:
- Aplikasi gratis dengan iklan.
- Dukungan: altomediaindonesia@gmail.com.

ENGLISH — v2.4.3
------------------------------------------------------------
BERUANG v2.4.3 — Branded Splash Screen & One-Way Tier Upgrades

The v2.4.3 update fixes 2 user-reported issues around the app launch
experience and the Tier Upgrade (Naik Kelas) feature.

Fixed in v2.4.3:
- DEFAULT ANDROID LOGO ON APP LAUNCH (splash fix): the stock Android
  splash theme falls back to a generic app icon when the splash icon is
  not set explicitly, so users briefly saw the "default Android logo".
  The splash icon now explicitly uses the BERUANG logo: the app opens
  straight into a BERUANG-branded splash and hands off smoothly to the
  loading screen.
- NO TIER DOWNGRADE: users could previously switch back to a lower tier
  via the "Gunakan" button in the Tier Upgrade sheet. Tiers are now
  one-way (upgrade only): passed tiers are shown as "Terlampaui" and
  cannot be selected, and the repository rejects any downgrade attempt
  ("Kelas akun tidak bisa diturunkan").

Technical notes:
- Android minSdk 23 (Android 6.0+) up to targetSdk/compileSdk 37.
- Built with Kotlin + Jetpack Compose, Supabase Kotlin 3.0.0,
  Coil (images), AdMob. AI backend: Supabase Edge Function (Groq).
- Backend: Supabase (Postgres, Auth, Storage, Realtime).
- Release signed with ALTOMEDIA.jks (alias kdsmedia).

Notes:
- Free app with ads.
- Support: altomediaindonesia@gmail.com.

BAHASA INDONESIA
------------------------------------------------------------
BERUANG v2.4.1 — Perbaikan Ekonomi Poin, Realtime & Pendaftaran

Pembaruan v2.4.1 memperbaiki 4 bug serius di sekitar ekonomi poin
(wallet), langganan realtime, dan alur pendaftaran.

Yang diperbaiki di v2.4.1:
- POIN SEKARANG TERHITUNG BENAR (fix kritis): transaksi baca-tulis
  (compare-and-swap) di `NodesRepository` dulu salah memproyeksikan kolom
  `path`, sehingga nilai selalu hilang dan semua aksi poin (check-in,
  like, follow, referral, invite, reward iklan, transfer, naik kelas)
  gagal commit tanpa suara. Kini proyeksi menyertakan kolom `path` dan
  mengembalikan nilai CAS yang benar.
- POIN KOMENTAR TAK LAGI GANDA (fix aritmatika): `HomeScreen` sebelumnya
  menambahkan poin komentar dua kali (UI + PostRepository). Kini hanya
  satu sumber (repository) yang mengaward, pemakaian kuota tetap tercatat.
- REALTIME LENGKAP (fix subscribe): langganan realtime pada leaf persis
  (`path = 'p'`) sebelumnya hanya menangapi UPDATE, sehingga insert/hapus
  pertama kali (PIN wallet, inviteReward, dsb.) tidak memicu refresh UI.
  Kini INSERT/UPDATE/DELETE disubscribe untuk filter EQ juga.
- PENDAFTARAN (fix blokir): hasil `bootstrapAdminAndCheckBlock` sebelumnya
  diabaikan saat daftar akun baru, sehingga akun yang diblokir tetap
  bisa masuk. Kini, sama seperti alur login, akun diblokir ditolak.
- VERSI & SIGNING: bump ke 2.4.1 (code 9); `.gitignore` kini mengabaikan
  `ALTOMEDIA/keystore.properties` agar kredensial tanda tangan lokal
  aman; build dirilis dengan keystore `ALTOMEDIA.jks` (alias `kdsmedia`)

Catatan teknis:
- Android minSdk 23 (Android 6.0+) sampai targetSdk/compileSdk 37.
- Dibangun dengan Kotlin + Jetpack Compose, Supabase Kotlin 3.0.0,
  Coil (gambar), AdMob. Backend AI: Supabase Edge Function (Groq).
- Backend: Supabase (Postgres, Auth, Storage, Realtime).

Catatan:
- Aplikasi gratis dengan iklan.
- Dukungan: altomediaindonesia@gmail.com.

ENGLISH — v2.4.1
------------------------------------------------------------
BERUANG v2.4.1 — Points Economy, Realtime & Registration Fixes

The v2.4.1 update fixes 4 serious bugs spanning the points (wallet)
economy, realtime subscriptions, and the registration flow.

Fixed in v2.4.1:
- POINTS COUNTED CORRECTLY (critical fix): the compare-and-swap
  read-write transaction in `NodesRepository` projected the wrong columns
  (`path` omitted), so row data was always discarded and every points
  action (check-in, like, follow, referral, invite, rewarded ads,
  transfer, tier purchase) silently failed. Now the projection includes
  `path` and returns correct CAS results.
- COMMENT POINTS NO LONGER DOUBLED (arithmetic fix): `HomeScreen` used to
  award the comment points twice (UI + PostRepository). Now only the
  repository awards; quota usage tracking remains intact.
- COMPLETE REALTIME (subscribe fix): subscriptions to an exact leaf
  (`path = 'p'`) previously only handled UPDATE, so first-time inserts or
  deletes (wallet PIN, inviteReward, etc.) never triggered UI refreshes.
  INSERT/UPDATE/DELETE are now subscribed for the EQ filter too.
- REGISTRATION CHECK (block fix): the `bootstrapAdminAndCheckBlock` result
  was ignored during registration, so blocked accounts could still get in.
  Now, as with login, blocked accounts are rejected with an error message.
- VERSION & SIGNING: bumped to 2.4.1 (code 9); `.gitignore` now ignores
  `ALTOMEDIA/keystore.properties` so local signing credentials stay safe;
  release signed with `ALTOMEDIA.jks` (alias `kdsmedia`)

Technical notes:
- Android minSdk 23 (Android 6.0+) up to targetSdk/compileSdk 37.
- Built with Kotlin + Jetpack Compose, Supabase Kotlin 3.0.0,
  Coil (images), AdMob. AI backend: Supabase Edge Function (Groq).
- Backend: Supabase (Postgres, Auth, Storage, Realtime).

Notes:
- Free app with ads.
- Support: altomediaindonesia@gmail.com.

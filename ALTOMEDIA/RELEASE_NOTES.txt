BAHASA INDONESIA
------------------------------------------------------------
BERUANG v2.2.0 — Tugas Bonus Undang Teman, Navigasi Kembali, & Perbaikan Iklan

Pembaruan v2.2.0 menambahkan tugas bonus undang teman, tombol kembali
yang konsisten di semua halaman/popup, serta perbaikan tampilan iklan
AdMob dan interval interstitial.

Yang baru & diperbaiki di v2.2.0:
- TUGAS BONUS UNDANG TEMAN: ajak 10 teman bergabung memakai kode
  referral dan dapatkan 5000 poin (sekali klaim). Kartu "Undang Teman"
  di halaman Tugas Bonus menampilkan progres X/10, tombol "Bagikan"
  untuk menyebar kode undangan (via share sheet Android), dan tombol
  "Klaim 5000" yang aktif otomatis setelah 10 teman bergabung.
- TOMBOL KEMBALI (⬅️) DI SEMUA HALAMAN/POPUP: kini semua layar overlay
  (Pesan, Aktivitas, Obrolan, Profil, dan panel Admin) memiliki tombol
  kembali yang jelas serta merespons tombol back sistem (BackHandler).
  Pada Profil, tombol back menutup modal yang terbuka dulu sebelum
  kembali. Dialog popup (AlertDialog) otomatis ditutup oleh back sistem.
- EDIT SALDO ADMIN (penyempurnaan): dialog atur saldo kini memakai
  pemilih mode Tambah/Kurangi, satu kolom nominal, kolom catatan,
  dan tombol OKE tunggal (dengan tombol Batal).
- IKLAN BANNER AdMob: perbaikan konteks activity, ukuran adaptive,
  dan ikat ke lifecycle agar banner tampil andal di semua layar.
- IKLAN INTERSTITIAL: cooldown 15 menit antar tampil, guard activity,
  dan reload otomatis setelah ditampilkan.
- IKLAN REWARD: perbaikan crash setelah iklan selesai.
- LOGO "K" sebelum splash dihapus.

Catatan teknis:
- Android minSdk 23 (Android 6.0+) sampai targetSdk/compileSdk 37.
- Dibangun dengan Kotlin + Jetpack Compose, Supabase Kotlin 3.0.0,
  Coil (gambar), AdMob.
- Backend: Supabase (Postgres, Auth, Storage, Realtime).

Catatan:
- Aplikasi gratis dengan iklan.
- Dukungan: altomediaindonesia@gmail.com.

ENGLISH — v2.2.0
------------------------------------------------------------
BERUANG v2.2.0 — Invite-Friends Bonus Task, Back Navigation, & Ad Fixes

The v2.2.0 update adds an invite-friends bonus task, consistent back
buttons across all screens/popups, and fixes to AdMob banner display
and interstitial cadence.

What's new / fixed in v2.2.0:
- INVITE-FRIENDS BONUS TASK: invite 10 friends to join using your
  referral code and earn 5000 points (one-time claim). The "Undang
  Teman" card on the Bonus Tasks screen shows live X/10 progress, a
  "Bagikan" button to share the invite code (via the Android share
  sheet), and a "Klaim 5000" button that auto-enables once 10 friends
  have joined.
- BACK BUTTON (⬅️) ON ALL SCREENS/POPUPS: all overlay screens (Messages,
  Activity, Chat, Profile, and the Admin panel) now have a clear back
  button and respond to the system back key (BackHandler). On Profile,
  back first closes any open modal before navigating back. AlertDialog
  popups are dismissed automatically by the system back key.
- ADMIN SALDO EDIT (refinement): the adjust-saldo dialog now uses an
  Add/Subtract mode picker, a single nominal field, a note field, and
  a single OK button (plus Cancel).
- ADMOB BANNER ADS: fixed activity context, adaptive size, and
  lifecycle binding so banners display reliably on all screens.
- INTERSTITIAL ADS: 15-minute cooldown between shows, activity guard,
  and automatic reload after display.
- REWARDED ADS: fixed a crash after the ad completed.
- Removed the stray "K" logo before the splash screen.

Technical notes:
- Android minSdk 23 (Android 6.0+) up to targetSdk/compileSdk 37.
- Built with Kotlin + Jetpack Compose, Supabase Kotlin 3.0.0,
  Coil (images), AdMob.
- Backend: Supabase (Postgres, Auth, Storage, Realtime).

Notes:
- Free app with ads.
- Support: altomediaindonesia@gmail.com.

BAHASA INDONESIA
------------------------------------------------------------
BERUANG v2.3.0 — Perbaikan Bug Checkin/Iklan, Ikon Tier, AI Gratis & Saldo

Pembaruan v2.3.0 memperbaiki sejumlah bug kritis (crash checkin & tonton
iklan, interstitial terlalu sering, saldo admin gagal), menambah ikon
kelas, menyempurnakan layar Pesan, dan mengganti AI ke provider gratis.

Yang baru & diperbaiki di v2.3.0:
- CHECK-IN HARIAN (fix crash): klik tombol check-in tidak lagi crash.
  Penyebab: toast ditampilkan dari background thread → kini thread-safe.
- TONTON IKLAN (fix crash): crash setelah iklan reward selesai diperbaiki
  (root cause sama: toast dari IO thread).
- INTERSTITIAL 30 MENIT (akurat): iklan interstitial kini tampil tepat
  30 menit sekali. Cooldown disimpan di SharedPreferences agar tidak reset
  saat app ditutup/dibuka ulang (sebelumnya bisa tampil lagi ~1 menit).
- IKON KELAS (naik kelas): tiap tier kini menampilkan ikon Material yang
  sesuai — Star, Bronze (WorkspacePremium), Silver, Gold (EmojiEvents),
  Master (MilitaryTech) — pada pill profil & kartu sheet "Naik Kelas".
- ATUR SALDO ADMIN (fix gagal): saldo kini selalu terperbarui setelah klik
  OKE. Sebelumnya gagal untuk wallet yang belum punya node saldo; kini
  fallback ke read-then-set bila transaksi CAS tidak commit.
- LAYAR PESAN (penyempurnaan): daftar kontak realtime (update otomatis),
  kolom pencarian teman, empty state, jumlah kontak di header, urut
  (admin/AI/alfabetis), area ketuk profil lebih besar.
- AI GRATIS (Groq, OpenAI-compatible): backend AI kini default memakai
  Groq — provider OpenAI-compatible GRATIS selamanya (API key gratis dari
  console.groq.com, tanpa kartu kredit/billing, model open-source).
  Tidak perlu lagi akun OpenAI berbayar. (Bisa tetap pakai OpenAI via env.)

Catatan teknis:
- Android minSdk 23 (Android 6.0+) sampai targetSdk/compileSdk 37.
- Dibangun dengan Kotlin + Jetpack Compose, Supabase Kotlin 3.0.0,
  Coil (gambar), AdMob. Backend AI: Supabase Edge Function (Groq).
- Backend: Supabase (Postgres, Auth, Storage, Realtime).

Catatan:
- Aplikasi gratis dengan iklan.
- Dukungan: altomediaindonesia@gmail.com.

ENGLISH — v2.3.0
------------------------------------------------------------
BERUANG v2.3.0 — Bug Fixes (Checkin/Ads), Tier Icons, Free AI & Saldo

The v2.3.0 update fixes several critical bugs (checkin & rewarded-ad
crashes, interstitial too frequent, admin saldo failing), adds tier icons,
refines the Messages screen, and switches AI to a free provider.

What's new / fixed in v2.3.0:
- DAILY CHECK-IN (crash fix): tapping the check-in button no longer
  crashes. Cause: toast shown from a background thread → now thread-safe.
- WATCH-AD (crash fix): crash after the rewarded ad completed is fixed
  (same root cause: toast from the IO thread).
- INTERSTITIAL 30 MIN (accurate): interstitials now show exactly every 30
  minutes. The cooldown is persisted in SharedPreferences so it survives
  app restarts (previously could re-show after ~1 minute).
- TIER ICONS (class upgrade): each tier now shows a matching Material icon
  — Star, Bronze (WorkspacePremium), Silver, Gold (EmojiEvents), Master
  (MilitaryTech) — on the profile pill & "Naik Kelas" sheet cards.
- ADMIN SALDO (fail fix): the balance now always updates after tapping OK.
  Previously failed for wallets with no balance node yet; now falls back to
  read-then-set when the CAS transaction doesn't commit.
- MESSAGES SCREEN (refinement): realtime contact list (auto-updates), a
  friend search field, empty state, contact count in the header, sorting
  (admin/AI/alphabetical), larger profile tap target.
- FREE AI (Groq, OpenAI-compatible): the AI backend now defaults to Groq
  — an OpenAI-compatible provider that is FREE forever (free API key from
  console.groq.com, no credit card/billing, open-source models). No paid
  OpenAI account needed anymore. (OpenAI still usable via env override.)

Technical notes:
- Android minSdk 23 (Android 6.0+) up to targetSdk/compileSdk 37.
- Built with Kotlin + Jetpack Compose, Supabase Kotlin 3.0.0,
  Coil (images), AdMob. AI backend: Supabase Edge Function (Groq).
- Backend: Supabase (Postgres, Auth, Storage, Realtime).

Notes:
- Free app with ads.
- Support: altomediaindonesia@gmail.com.

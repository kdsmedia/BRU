BAHASA INDONESIA
------------------------------------------------------------
BERUANG v2.0.0 — Migrasi Penuh ke Android Native (Kotlin + Jetpack Compose)

Pembaruan besar: BERUANG kini ditulis ulang sepenuhnya sebagai
aplikasi Android NATIVE menggunakan Kotlin dan Jetpack Compose —
menggantikan versi sebelumnya yang berbasis pembungkus HTML (Capacitor).
Tampilan, fitur, dan alur aplikasi tetap identik, namun kini jauh
lebih cepat, lebih ringan, dan lebih hemat data karena tidak lagi
memuat webview.

Yang baru & diperbaiki di v2.0.0:
- ARSITEKTUR NATIVE: seluruh antarmuka kini dirender dengan Jetpack
  Compose (Material 3), bukan HTML/webview. Navigasi, animasi, dan
  respons sentuh kini secepat aplikasi Android asli.
- PERFORMANCE: startup lebih cepat, penggunaan memori lebih rendah,
  dan konsumsi data berkurang signifikan karena tidak ada layer web.
- Pull-to-refresh di feed beranda: tarik ke bawah untuk memuat ulang
  postingan terbaru (menggantikan indikator #ptr-indiger versi web).
- Like dengan double-tap: ketuk ganda pada gambar postingan untuk
  menyukai, persis seperti versi sebelumnya.
- Baris WhatsApp di Pengaturan: tautan langsung ke channel WhatsApp
  resmi BERUANG kini tersedia di menu Pengaturan.
- BACKEND: migrasi ke Supabase Kotlin SDK 3.0 (realtime, autentikasi,
  penyimpanan, dan query dengan API DSL terbaru). Realtime kini
  menggunakan StateFlow untuk pembaruan langsung yang lebih andal.
- Fitur lengkap dipertahankan: feed & stories, komentar, chat real-time,
  profil dengan tier berlangganan, dompet/QR, upload media, notifikasi,
  panel admin, sistem tier harian (Star/Bronze/Silver/Gold/Master),
  iklan AdMob (banner/interstitial/reward) dengan persetujuan UMP.
- Keamanan: kunci Supabase (anon/service-role) dikelola di luar repo
  (out-of-band), tidak pernah dikomit ke repositori.

Catatan teknis:
- Android minSdk 23 (Android 6.0+) sampai targetSdk/compileSdk 37.
- Dibangun dengan Kotlin + Jetpack Compose (BOM 2024.09.03),
  Supabase Kotlin 3.0.0, Coil (gambar), AdMob.
- Backend: Supabase (Postgres, Auth, Storage, Realtime).

Catatan:
- Aplikasi gratis dengan iklan.
- Dukungan: altomediaindonesia@gmail.com.

ENGLISH — v2.0.0
------------------------------------------------------------
BERUANG v2.0.0 — Full migration to native Android (Kotlin + Jetpack Compose)

A major rewrite: BERUANG is now a fully native Android app built with
Kotlin and Jetpack Compose, replacing the previous HTML-wrapper
(Capacitor) version. The look, features, and flows remain identical,
but the app is now much faster, lighter, and more data-efficient
because it no longer loads a webview.

What's new / fixed in v2.0.0:
- NATIVE ARCHITECTURE: the entire UI is now rendered with Jetpack
  Compose (Material 3) instead of HTML/webview. Navigation, animation,
  and touch response are now as fast as a native Android app.
- PERFORMANCE: faster startup, lower memory usage, and significantly
  reduced data consumption with no web layer.
- Pull-to-refresh on the home feed: pull down to reload the latest
  posts (replaces the web #ptr-indicator).
- Double-tap to like: double-tap a post image to like it, just like
  before.
- WhatsApp row in Settings: a direct link to the official BERUANG
  WhatsApp channel is now available in the Settings menu.
- BACKEND: migrated to Supabase Kotlin SDK 3.0 (realtime, auth,
  storage, and queries with the new DSL API). Realtime now uses
  StateFlow for more reliable live updates.
- All features retained: feed & stories, comments, real-time chat,
  profile with subscription tiers, wallet/QR, media upload,
  notifications, admin panel, daily tier system
  (Star/Bronze/Silver/Gold/Master), AdMob ads
  (banner/interstitial/reward) with UMP consent.
- Security: Supabase keys (anon/service-role) are managed
  out-of-band and never committed to the repository.

Technical notes:
- Android minSdk 23 (Android 6.0+) up to targetSdk/compileSdk 37.
- Built with Kotlin + Jetpack Compose (BOM 2024.09.03),
  Supabase Kotlin 3.0.0, Coil (images), AdMob.
- Backend: Supabase (Postgres, Auth, Storage, Realtime).

Notes:
- Free app with ads.
- Support: altomediaindonesia@gmail.com.
